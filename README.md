# 米拉奇战纪 Milaqi

双人实时对抗策略游戏：两名玩家各为一国之主，用每回合的经济购买兵种投入战场，
兵种自动前进、索敌、战斗。战后按双方存活单位的**杀戮值差值**对敌方城邦造成伤害，
先把对方城邦生命打光的一方获胜。

## 直接开玩

下载 [最新 Release](https://github.com/Lwangt/milaqi/releases/latest) 解压后双击 `Milaqi.exe`；
或者用仓库里的快捷启动器：`启动/` 目录下有 6 个 .bat（正常启动 / 测试模式 / AI 演示 / 3D 图鉴 / 开房 / 加入）。

### 联机（填对方 IP）

1. **主机方**：点「创建房间」（默认端口 27015），界面会显示本机 IP
2. **加入方**：在「主机 IP」填入该地址，端口一致，点「加入房间」
3. 主机方需在 Windows 防火墙放行该 UDP 端口

| 场景 | 能否直连 | 需要做什么 |
|---|---|---|
| 同一局域网 | ✅ | 防火墙放行 UDP 端口 |
| 主机有公网 IP | ✅ | 路由器端口映射 |
| 双方都在家庭 NAT 后 | ❌ | 需要中继/房间服务器，或 Steam P2P |

## 玩法

```
备战(35s) → 交战(最长30s) → 结算(按杀戮值差扣城邦血，然后清空战场) → 下一回合
```

| 系统 | 说明 |
|---|---|
| 经济 | 基础 5 金 + 利息（10%，上限 5）+ 连胜连败奖励 |
| 等级/人口 | 买经验升级；**人口上限 = 等级 + 1** |
| 兵种解锁 | **按等级解锁**（Lv1/3/5/7/9/11），等级不够不会出现在商店 |
| 商店 | 列出全部已解锁兵种，翻页任选；卡片显示层级/立绘/金币价/人口；悬浮看属性，点 ⓘ 看可旋转 3D 模型 |
| 部队 | 买下的兵**永久属于你**；买来先进【待出战队列】，选中后点战场布置；每回合满血重新上阵 |
| 战斗 | 自动前进索敌；伤害 = 物攻×(1−物防/(物防+75)) + 魔攻×(1−魔防/(魔防+75))，含 20% 伤害下限 |
| 结算 | `伤害 = max(0, 我方存活杀戮值 − 敌方存活杀戮值)` |
| 遗物 | 每 2 回合三选一（成长/战力/兵种/羁绊/技能强化） |
| 宝石 | 成长型遗物产出；商店买遗物与技能强化，下回合生效 |
| 流派 | 7 大流派各有固有**印记加成** |

### 操作

左键点卡片购买（一次一只）→ 队列里选中 → 点战场自己那半边放下；**右键点战场上的兵可出售**。

`空格` 开始战斗 · `E` 买经验 · `D` 自动布阵 · `G` 宝石商店 · `M` 菜单 · `F5` 重开

## 更新记录

### v0.6.0 流派平衡大修（极差 86.8% → 7.1%）

**根因一：AI 选兵被「等级分」淹没。** `UnitScore` 里 `d.tier * 12` 让 T5 比 T2 光等级就多 36 分，
远超流派名单 55 分的惩罚。结果**所有流派都退化成「堆最高本的前排兵」**——
「万箭齐发」一个弓箭手都不买、「奥术洪流」一个法师都不买。
修复：等级权重 12 → 5，流派权重 18 → 34，前排约束权重 190 → 120、后排惩罚 -55 → -34。

**根因二：印记加成覆盖率差异巨大。** 暗影突袭全队都是刺客/骑兵 → 100% 吃加成；
英雄荣耀只有 3/11 单位吃得到。改成按**实际出兵构成**配平每一条印记。

**新增机制：战斗后期伤害递增。** 坦克流对撞会拖到 45 秒上限（超时率一度到 8.6%），
现在 18 秒后伤害逐秒递增（每秒 +14%），强制打破僵局 → 超时率降到 **1.6%**。

> 调参方法：`matrix` 跑流派两两胜率矩阵，按灵敏度（约 2.3 分/1% 加成）两点插值迭代收敛。

### v0.5.1 华丽 HUD
生成錾金九宫格面板、圆形头像框、阵营徽记并接入顶栏/侧栏/卡牌。

### v0.5.0 美术大升级（2D）
- **兵种精灵**：程序化生成 51 个兵种的 Q 版角色，每个 20 帧（待机 6 / 行走 8 / 攻击 6），
  按标签派生 15 种外观原型（人形 / 盾卫 / 骑兵 / 法师 / 亡灵 / 机械 / 巨兽 / 刺客 / 英雄 /
  巨龙 / 元素 / 植物 / 蜘蛛 / 石像鬼 / 海妖），带描边、明暗、发光眼、披风、坐骑、武器
- **战场**：整张无接缝草地贴图（草叶纹理 + 花石 + 中央踩踏小径 + 边缘压暗），替换原暗色石板
- **动作系统**：BattleView 加入动作状态机，单位按「攻击 > 行走 > 待机」自动切换并左右翻转
- **卡牌**：商店与队列图标改用新精灵（头肩特写），移除启动时的 3D 立绘烘焙（启动更快）
- **渲染路径**：整体切换为 2D，删掉 3D 战场与三维开销

> 美术全部由 `tools/` 下的 Python 脚本程序化生成，改配色或装备后重跑脚本即可，
> 无需手绘、不依赖外部素材。

## 平衡调优记录（踩过的坑）

| 现象 | 根因 | 修复 |
|---|---|---|
| 纯战斗左右偏差 18% | 单位处理顺序固定，左方永远先手 | 每 tick 用种子随机数打乱处理顺序 |
| 近战阵容仍偏 9% | `Separate()` 边遍历边改坐标，累加结果依赖列表顺序 | 改为先累加推力再统一应用 |
| 所有对局完全相同 | 战斗随机数是写死的常量 | 用对局种子初始化 |
| 部署位置左右不同 | 双方各自抽随机数 | 改为严格镜像的确定性阵型 |
| 整体左右偏差 12~27% | 双方共用随机数流、固定 0 号先结算 | 每回合交替结算顺序 |
| 第一回合输就永远翻不了身 | 存活单位跨回合保留导致死循环 | 改为永久名册 + 每回合满血重上阵 |
| 高防单位对低攻兵免疫 | 减伤公式无下限 | 加 20% 伤害下限 |
| 高费卡性价比倒挂 | 每金战力随层级递减 | 层级曲线改为递增（0.50→1.14） |
