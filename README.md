# 米拉奇战纪 Milaqi

双人实时对抗的策略游戏：两名玩家各为一国之主，用每回合获得的经济购买兵种投入战场，
兵种自动前进、索敌、战斗。战后按双方存活单位的**杀戮值差值**对敌方城邦造成伤害，
先把对方城邦生命打光的一方获胜。

- 引擎：**Godot 4.6.1 (.NET)** ｜ 语言：**C# (net8.0)** ｜ 联机：**ENet(UDP) 主机权威**
- 已实现：回合经济 / 云顶式等级与人口 / 34 兵种 / 37 遗物 / 8 技能 / 宝石商店 / IP 直连联机 / AI 对手

---

## 快速开始

### 1. 直接玩（已打包好的可执行文件）

```
build/windows/Milaqi.exe
```

双击运行 → 选择「单机测试：对战 AI」即可开始。

### 2. 联机对战（填对方 IP）

1. **主机方**：运行游戏 → 填写端口（默认 27015）→ 点「创建房间」→ 界面会显示本机 IP（如 192.168.1.20）
2. **加入方**：运行游戏 → 在「主机 IP」填入主机的 IP → 端口一致 → 点「加入房间」
3. 主机方需要在 Windows 防火墙放行该 UDP 端口。

| 场景 | 能否直连 | 需要做什么 |
|---|---|---|
| 同一局域网 | ✅ | 防火墙放行 UDP 端口 |
| 主机有公网 IP | ✅ | 路由器做端口映射 (Port Forwarding) |
| 双方都在家庭 NAT 后 | ❌ | 需要中继/房间服务器，或改用 Steam P2P |

### 3. 从源码运行 / 打包

```powershell
# 需要 .NET SDK 8+ 与 Godot 4.6.1 .NET 版
dotnet build Milaqi.csproj
godot --path . -- --local --demo          # 直接跑一局 AI 对 AI
godot --headless --path . -- --selftest   # 无窗口自检
godot --headless --path . --export-release "Windows Desktop" build/windows/Milaqi.exe
```

## 玩法要点

| 系统 | 说明 |
|---|---|
| 经济 | 每回合基础 5 金 + 利息(金币的 10%，上限 5) + 连胜/连败奖励 |
| 等级/人口 | 买经验升级；**人口上限 = 等级 + 1**，每个兵种占用 1~5 人口，人海战术无法无脑铺开 |
| 商店 | 5 个槽位，按等级概率抽取 T1~T5，花 2 金刷新；兵种随回合解锁 |
| 战斗 | 部署后自动前进、索敌、攻击；伤害 = 物攻×(1-物防/(物防+50)) + 魔攻×(1-魔防/(魔防+50)) |
| 结算 | 每回合结束：`伤害 = max(0, 我方存活杀戮值 - 敌方存活杀戮值)`，直接扣对方城邦生命 |
| 遗物 | 每 2 回合三选一；分成长型/战力型/兵种型/羁绊型/技能强化型 |
| 宝石 | 成长型遗物产出；宝石商店可买遗物与技能强化，**下回合生效** |
| 技能 | 战斗中点击技能按钮再点战场释放（陨石/治疗/冰霜/号角/召唤/奥术/荆棘/死亡凝视） |

完整设计见 [docs/01-游戏设计文档.md](docs/01-游戏设计文档.md)，技术选型见 [docs/00-技术方案选型决策文档.md](docs/00-技术方案选型决策文档.md)。

## 目录结构

```
data/                 游戏数值（纯 JSON，改数值不用改代码）
  units.json          34 个兵种
  relics.json         37 件遗物
  skills.json         8 个技能
  balance.json        经济/等级/商店概率/战斗参数
src/Core/             纯 C# 逻辑层（不依赖 Godot，可独立测试）
  Definitions.cs      数据模型与加载
  StatResolver.cs     遗物/羁绊对属性的结算
  BattleSim.cs        战斗模拟（前进/索敌/攻击/技能/死亡召唤）
  Match.cs            回合状态机、经济、商店、遗物、结算
  AiController.cs     AI 对手（也用于批量平衡测试）
  Snapshot.cs         联机状态快照序列化
src/Game/             Godot 表现层
  Main.cs             入口、指令路由、固定步长主循环
  BattleView.cs       战场渲染（单节点 _Draw，逻辑与表现分离）
  Hud.cs              战斗 HUD / 商店 / 遗物弹窗 / 宝石商店
  StartMenu.cs        开始菜单（单机 / 开房 / 填 IP 加入）
src/Net/NetManager.cs ENet 联机（主机权威 + 指令 + 快照）
tests/Milaqi.Tests/   headless 自检 + 批量 AI 对战平衡测试
```

## 开发工具

```powershell
cd tests/Milaqi.Tests
dotnet run -- selftest      # 数据与系统自检
dotnet run -- batch 200     # 200 局 AI 对战，输出回合数/胜率偏差/超时率
```

游戏内调试参数：

```
--local            直接开始单机对局（跳过菜单）
--demo             双方都由 AI 托管（看戏/录屏用）
--shots=5,45,90    在指定秒数自动截图到 build/shots/ 后退出
--selftest         无窗口自检模式，用于验证打包后的 exe
```

快捷键：`空格` 开始战斗 · `R` 刷新商店 · `E` 买经验 · `D` 自动部署 · `G` 宝石商店 · `M` 菜单 · `F5` 重开
