# 米拉奇战纪 Milaqi

双人实时对抗的策略游戏：两名玩家各为一国之主，用每回合获得的经济购买兵种投入战场，
兵种自动前进、索敌、战斗。战后按双方存活单位的**杀戮值差值**对敌方城邦造成伤害，
先把对方城邦生命打光的一方获胜。

## 直接开玩

下载 [最新 Release](https://github.com/Lwangt/milaqi/releases/latest) 里的 `Milaqi-v0.2.0-windows-x64.zip`，解压后双击 `Milaqi.exe`。

### 联机（填对方 IP）

1. **主机方**：点「创建房间」（默认端口 27015），界面会显示本机 IP（如 192.168.1.20）
2. **加入方**：在「主机 IP」填入该地址，端口一致，点「加入房间」
3. 主机方需在 Windows 防火墙放行该 UDP 端口

| 场景 | 能否直连 | 需要做什么 |
|---|---|---|
| 同一局域网 | ✅ | 防火墙放行 UDP 端口 |
| 主机有公网 IP | ✅ | 路由器做端口映射 (Port Forwarding) |
| 双方都在家庭 NAT 后 | ❌ | 需要中继/房间服务器，或改用 Steam P2P |

## 玩法要点

| 系统 | 说明 |
|---|---|
| 经济 | 每回合基础 5 金 + 利息（金币的 10%，上限 5）+ 连胜/连败奖励 |
| 等级/人口 | 买经验升级；**人口上限 = 等级 + 1**，每个兵种占 1~5 人口 |
| 商店 | **直接列出全部已解锁兵种**，左右翻页浏览；卡片显示立绘 + 金币价 + 人口，鼠标悬浮看完整属性；无抽卡、无刷新 |
| 部队 | 买下的兵**永久属于你**，每回合全员满血重新上阵；战斗中阵亡不会失去它 |
| 战斗 | 自动前进、索敌、攻击；伤害 = 物攻×(1−物防/(物防+75)) + 魔攻×(1−魔防/(魔防+75))，且有 20% 伤害下限 |
| 结算 | `伤害 = max(0, 我方存活杀戮值 − 敌方存活杀戮值)`，直接扣对方城邦生命 |
| 遗物 | 每 2 回合三选一；成长型/战力型/兵种型/羁绊型/技能强化型 |
| 宝石 | 成长型遗物产出；商店可买遗物与技能强化，**下回合生效** |
| 技能 | 战斗中选技能再点战场释放（陨石/治疗/冰霜/号角/召唤/奥术/荆棘/死亡凝视） |
| 流派 | 7 大流派各有固有**印记加成**；4 档 AI 难度（简单/普通/困难/噩梦） |
| 界面 | 金币/宝石/人口/等级等全部用**小图标 + 数字**表示，不用中文标签 |

### 操作

左键点战场**自己那半边**部署部队，**右键点自己的兵可以出售**（返还 60% 金币，用来腾人口换强兵）。

`空格` 开始战斗 · `E` 买经验 · `D` 自动部署 · `G` 宝石商店 · `M` 菜单 · `F5` 重开

```
data/                 游戏数值（纯 JSON，改数值不用改代码、不用重新编译）
  units.json          34 个兵种
  relics.json         37 件遗物
  skills.json         8 个技能
  archetypes.json     7 大流派 + 4 档 AI 难度
  balance.json        经济/等级/商店概率/战斗参数
art/units/*.svg       34 个兵种立绘（身体+护甲+武器分层，运行时按阵营染色，可直接替换）
art/ui/*.svg          19 个界面图标（金币/宝石/人口/生命/攻击/防御…）
src/Core/             纯 C# 逻辑层（不依赖 Godot，可独立测试）
  BattleSim.cs        战斗模拟：前进/索敌/攻击/溅射/顺劈/吸血/减速/召唤
  Match.cs            回合状态机、经济、商店、遗物、名册、结算
  StatResolver.cs     遗物 / 羁绊 / 流派印记对属性的结算
  AiController.cs     流派化 AI（也是批量平衡测试的执行体）
  Snapshot.cs         联机状态快照序列化
src/Game/             Godot 表现层
  Main.cs             入口、指令路由、固定步长主循环
  BattleView.cs       战场渲染（单节点批绘制 + 弹道/飘字/死亡特效）
  UnitArt.cs          兵种贴图加载（缺失自动回退程序化绘制）
  Hud.cs              战斗 HUD（图标化资源栏）/ 遗物弹窗 / 宝石商店
  ShopPanel.cs        兵种商店（分页卡片 + 悬浮属性详情）
  UiArt.cs            界面图标加载
  StartMenu.cs        开始菜单（单机 / 开房 / 填 IP 加入）
src/Net/NetManager.cs ENet 联机（主机权威 + 指令 + 快照）
tests/Milaqi.Tests/   headless 自检 + 批量对战 + 流派矩阵 + 难度阶梯 + 逐回合诊断
```

## 从源码运行 / 打包

```powershell
# 需要 .NET SDK 8+ 与 Godot 4.6.1 .NET 版
dotnet build Milaqi.csproj
godot --path . -- --local --demo            # AI 对 AI 看戏
godot --headless --path . -- --selftest     # 无窗口自检
godot --headless --path . --export-release "Windows Desktop" build/windows/Milaqi.exe
```

游戏内调试参数：`--local`（跳过菜单直接开局）、`--demo`（双方 AI 托管）、
`--shots=5,45,90`（在指定秒数自动截图到 build/shots/）、`--selftest`（打包后验证数据完整性）、
`--host --port=27015` / `--join=IP`（命令行直连联机，用于自动化测试）、`--tipdebug`（强制显示商店悬浮详情，方便截图检查）。

## 平衡测试工具

```powershell
cd tests/Milaqi.Tests
dotnet run -- selftest      # 22 项数据与系统自检
dotnet run -- batch 200     # 200 局 AI 对战：回合数 / 战斗时长 / 左右胜率偏差
dotnet run -- matrix 16     # 7 大流派两两对战胜率矩阵
dotnet run -- ladder 60     # AI 难度阶梯
dotnet run -- battle 400    # 纯战斗隔离测试（同阵容，检验战斗本身是否公平）
dotnet run -- diag greed undead_swarm   # 单局逐回合诊断，打印双方部队与遗物
```
